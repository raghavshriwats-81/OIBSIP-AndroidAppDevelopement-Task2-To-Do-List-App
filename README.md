# Raghav's To-Do List App 📝

A clean, responsive, and lightweight Android application built using Java and XML layout components. It allows users to manage their daily tasks with real-time UI updates.

---

## 🚀 Features
- **Add Tasks:** Quickly add new daily tasks to your list.
- **Delete Tasks:** Long-press (tap & hold) on any item to remove it.
- **Dynamic List Handling:** Powered by `ArrayList` and `ArrayAdapter` for seamless updates.
- **Clean UI:** Intuitive and minimalist interface designed for smooth user interaction.

---

## 🛠️ Tech Stack
- **Language:** Java
- **UI Design:** Android XML Layouts
- **IDE:** Android Studio
- **Minimum SDK:** API 21 (Android 5.0 Lollipop)
